UI Görsel değişiklik – mantık aynı MANTIK Davranış değişikliği YENİ Hiç olmayan dosya/özellik FİX Hata düzeltmesi

📄 src/index.css UI

Önce: Sadece @import "tailwindcss"; vardı. Tailwind aktif ama hiçbir renk tanımlanmamıştı.

Sonra: @theme { ... } bloğu eklendi. Bu blok, projenin her yerinde kullanılacak renk ve yazı tipi isimlerini tanımlıyor.

  • --color-primary → yeşil (#2D6A4F). Buton, aktif link gibi yerlerde kullanılıyor.
  • --color-background, --color-surface, --color-border → sayfa arka planı, kart arka planı, çizgi renkleri.
  • --color-text, --color-text-secondary, --color-text-muted → üç farklı yazı rengi tonu.
  • --shadow-card → kartların hafif gölgesi.

Bu değişkenler sayesinde bg-primary, text-text-secondary gibi Tailwind class'larını her dosyada kullanabiliyorsun.

⚙️ vite.config.ts FİX

Önce: plugins: [react()] – Tailwind import edilmiş ama plugins dizisine eklenmemişti. Bu yüzden @theme bloğundaki renkler tanımlansa bile Tailwind class'ları üretilmiyordu.

Sonra: plugins: [react(), tailwindcss()] – Tailwind artık Vite'ın build sürecine dahil.
